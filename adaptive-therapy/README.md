# adaptive-therapy

Model predictive control of adaptive therapy for metastatic castration-resistant prostate
cancer, using evolutionary game theory models as the controller's internal model.

Corresponds to **Chapters 5 and 6** of the thesis.

**This part is reproducible in full.** It depends on no restricted data: every parameter
and every scenario is in the repository.

---

## What is here

```
controllers/    the two closed-loop controllers
calibration/    calibration of N_max
analysis/       sensitivity sweeps, equilibria and stability
baselines/      the LV-MPC baseline used for comparison
params/         every parameter value, in JSON and CSV
```

## The two models

The plant is a **Lotka–Volterra** competition model in absolute cell populations. Two
instantiations are used, and they are not interchangeable:

| | Single-agent | Dual-agent |
|---|---|---|
| Source | Cunningham et al. | West et al. |
| Populations | 3 (`T+`, `TP`, `T-`) | 4 (`T+`, `TP`, `T-/+`, `T-/-`) |
| Drugs | Abiraterone | Abiraterone + Docetaxel |
| `K_TP` | `1e4 - 9.9e3*u_a` (linear) | `1e4 / 10^(2*u_a)` (exponential) |

**The form of `K_TP` differs between the two.** This is not an inconsistency: each
scenario follows the model it is compared against. See `params/parameters.json`.

The controller's internal model is either the same Lotka–Volterra system (the LV-MPC
baseline) or a **replicator equation with a fictitious zone** operating on frequencies
`x = y / N_max`. The mismatch between the second and the plant is deliberate: it is the
experiment the thesis reports.

## Running it

Requires `numpy`, `scipy`, `casadi`, `matplotlib`.

```bash
# closed loop, single agent
python controllers/MPC_Replicator_SA_V3.py

# closed loop, dual agent
python controllers/MPC_Replicator_DA_V3.py

# equilibria and stability of both models (numpy + scipy only)
python analysis/Equilibrios_Estabilidad.py
```

The sensitivity sweeps are long. The dual-agent IV-Opt sweep at `H_p = 100` takes weeks
per configuration on a server; the blocking strategy (`B_w > 1`) exists to make that
tractable. Do not launch them casually.

## What is not here

Superseded versions of these scripts (`_V1`, `_V2`, and the pre-calibration `MPC_Replicator_*`)
are not published. Where several versions of a procedure exist, only the one that produced
the reported result is included. See `CHANGES-FROM-THESIS.md` at the repository root.

## Caveat on the results

The simulation studies are a **proof of concept**. The reported extensions of time to
progression, the reductions in cumulative dose and the long control horizons are
hypotheses generated by these models, not dosing recommendations, and they rest on
assumptions of full state observability, noise-free measurement, fixed phenotypes and
patient-independent parameters. The thesis states this in its own terms; it is repeated
here so that nobody running this code mistakes its output for clinical evidence.
